# Футбол з друзями — фронтенд

React 19 + TypeScript + Vite + Tailwind v4 + TanStack Query + Radix UI.

Правила для UI — у [`../CLAUDE.md`](../CLAUDE.md), перелік компонентів — у [`INVENTORY.md`](INVENTORY.md).

Запускається з кореня репозиторію разом з API — див. [`../README.md`](../README.md).
`npm run dev` тут піднімає лише Vite; запити `/api` він проксіює на `http://localhost:3000`.

## Що є

- **Календар** (`/`) — місяць / тиждень (на телефоні тиждень списком), стан у URL (`?view=week&date=2026-09-21`).
  Клік по грі відкриває картку з деталями і швидким записом. Організатор створює гру кліком по вільній годині/дню.
- **Гра** (`/games/:id`) — час і місце, «точно буду» / «можливо не зможу», хто відповідає за м'яч і манішки,
  список учасників, поділ на команди (чернетка → перемішати / переставити вручну → зберегти).
- **Розстановка** (`/lineup`) — поле з розстановкою двох команд. Поки лише верстка на статичних даних
  (`src/features/lineup/mockLineup.ts`), без зв'язку з грою.
- **Гравці** (`/players`) — рівні гри (1–5); організатор редагує їх прямо в списку.
- **Вхід / реєстрація** (`/login`, `/register`) і **профіль** (`/profile`) — ім'я, зміна пароля, вихід.

Типи, константи й правила гри (фаза, місця, актуальність складів) — у пакеті `@futbol/shared` (`../shared/src`).

## Структура

```
src/
  api/          контракт Api, HTTP-клієнт, хуки React Query
  features/
    auth/       форми входу й реєстрації
    profile/    форми профілю й пароля
    calendar/   сітки, поповер, міні-календар
    games/      картки сторінки гри, форма створення/редагування
    teams/      balanceTeams (алгоритм) + UI поділу
    players/    рядки й фільтри сторінки гравців
    lineup/     поле, фішки гравців, статичні дані розстановки
  components/   UI-кіт і каркас (сайдбар, рамка)
  pages/        маршрути
```

## Бекенд

Уся робота з даними йде через інтерфейс `Api` (`src/api/types.ts`), реалізація — `src/api/httpApi.ts`.
Сесія живе в httpOnly-cookie; якщо сервер відповів 401, кеш «я» скидається і `RequireAuth` веде на `/login`.

## Стиль

Усі кольори й радіуси — токени в `src/index.css` (`@theme`). Перехід на стиль NVIDIA — це заміна токенів.
